# 📱 Tataboq App

Tataboq is a Flutter-based mobile application built using Dart and Flutter, designed to provide a modern and responsive mobile experience.

## 🚀 Features

- Cross-platform mobile application (Android & iOS).
- Responsive and user-friendly interface.
- Modern Flutter UI components.
- Clean and maintainable code structure.

## 🛠️ Technologies Used

- Flutter
- Dart
- Material Design

## 📋 Requirements

Before running the project, make sure you have:

- Flutter SDK installed.
- Dart SDK installed.
- Android Studio or VS Code.
- Android Emulator or a physical device.

## 📦 Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd tataboq_app
```

Install dependencies:

```bash
flutter pub get
```

## ▶️ Run the Application

Start the application:

```bash
flutter run
```

## 🏗️ Build

Build APK for Android:

```bash
flutter build apk --release
```

Build for iOS:

```bash
flutter build ios --release
```
